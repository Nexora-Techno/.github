
# Support

Welcome to Nexora-Techno Support.

We aim to make it easier for users, developers, and contributors to find assistance with our projects.

## Where to Get Help

### 1. Documentation

Before requesting support, review the documentation and README files of the relevant project.

Documentation is often the fastest way to resolve common questions.

### 2. GitHub Discussions

For general questions, technical discussions, ideas, and community assistance, use GitHub Discussions when enabled.

Organization Discussions:

https://github.com/orgs/Nexora-Techno/discussions

### 3. GitHub Issues

Use GitHub Issues for:

- Confirmed software bugs.
- Reproducible problems.
- Feature requests.
- Documentation errors.

Please select the appropriate issue template.

Issues should not be used as a substitute for general technical support.

### 4. Project-Specific Support

Some projects may maintain their own support channels and troubleshooting documentation.

Always check the relevant repository for project-specific instructions.

## Before Requesting Support

Please provide:

- Project name.
- Software version.
- Operating system and relevant environment details.
- A clear description of the problem.
- Steps to reproduce the issue.
- Relevant error messages or logs.

Remove passwords, access tokens, private keys, and personal information before sharing logs.

## Security Issues

Never report security vulnerabilities through public Issues or Discussions.

Follow the instructions in SECURITY.md.

## Response Expectations

Nexora-Techno is committed to reviewing support requests responsibly.

However:

- Response times are not guaranteed.
- Support availability may vary between projects.
- Community contributions are voluntary unless otherwise specified.
- Not every request can be resolved or implemented.

## Contributing to Support

Community members are encouraged to help others by sharing accurate information, documentation, and reproducible solutions.

Please remain respectful and constructive.
